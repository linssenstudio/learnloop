## P0 验收标准（本仓库 DoD）

上传真实 PDF/DOCX/PPTX → 解析出章节与页码 → 输入学习目标并完成 3–5 题诊断 → 生成 ≥5 单元课纲（可编辑）→ 进入第 1 节课：AI 教师分步讲解、引用资料页码、主动提问 → 答错触发错因分析与补救讲解 → 随堂 3–5 题真实批改并写掌握度 → 生成笔记/复习卡 → 退出重新登录后课程、消息、掌握度、任务完整恢复。

## 明确不做假的地方

- 未配置 `LLM_API_KEY` 时，所有 AI 接口返回 `503 LLM_NOT_CONFIGURED`，前端显示配置指引；绝不返回预写假回复。
- 上传进度、解析状态、生成进度全部来自数据库真实状态轮询。
- 未实现功能在 UI 中标注「开发中」，不出现假按钮。
