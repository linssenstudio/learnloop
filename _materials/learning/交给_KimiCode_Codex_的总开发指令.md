## 技术默认项（环境不支持时先给出替代及理由）

- Web：Next.js（App Router） + TypeScript + Tailwind + shadcn/ui。
- API/Agent：Python FastAPI + Pydantic + Agent orchestration，提供强类型接口。
- DB：PostgreSQL + pgvector，Prisma/SQLAlchemy 选择一条清晰链路。
- 文件：S3 兼容对象存储；异步后台：Redis + worker 或可靠的任务平台。
- 模型接口：多模型适配层，配置 Gemini、OpenAI 等，支持回退与费用记录。
- 课程白板：tldraw/自研可控画布 + KaTeX + Mermaid/SVG；AI 输出安全动作 JSON，不执行任意代码。
- 文件解析：PDF、DOCX、PPTX 优先，音频转写后续支持；支持页码/时间戳引用。
- 视频：先实现可导出 MP4 的 SVG/HTML 动画 + TTS + FFmpeg，复杂学科动画在下一阶段增加 Manim。

## 首版必须能演示的完整流程

输入：我想学习如何搭建一个内容 Agent；已有 3 份课程资料（PDF/PPTX/DOCX）。

平台：
1. 支持真实文件上传并解析，不通过“样例数据”模拟完成。
2. 提出基本能力诊断问题，并根据回答生成 5 单元课程纲要。
3. 将课纲及资料关联并保存到数据库。
4. 进入第一节课，AI 教师解释概念、引用资料，包含主动提问。
5. 我回答错误，老师分析错因、改用类比重新讲解、再次考查。
6. 随堂生成 3–5 题，真实批改并记录知识掌握度。
7. 自动生成学习笔记、复习卡片或下一节课程任务。
8. 关闭网页并重新登录后课程、消息、掌握度和任务仍在。

优先完成这条闭环，再逐阶段构建白板、深度学习、资料工厂、视频、计划、学习者画像、LMS 集成、课程广场、语音和团队功能。

## 互动白板必须实现的机制

- AI Teacher 只生成通过 JSON Schema 验证的步骤：`narration`、`board_actions`、`check_question`、`source_refs`。
- 支持白板类型：文本、箭头、矩形、思维连接、代码、公式、图表、重点标注。
- 前端提供暂停/继续、上一页/下一页、回放、随时提问、将当前步骤添加笔记。
- 对于「这一点我没懂」操作，要暂停课程主线并生成补救讲解，学会后回到主线。
- 用真实服务端事件流（SSE/WebSocket）传输白板步骤；防重复、可中断、可重试。

## 教学 Agent 最低行为标准

实现教学状态机：`DIAGNOSE→PLAN→EXPLAIN→DEMONSTRATE→CHECK→REMEDIATE/ADVANCE→APPLY→SUMMARIZE→SCHEDULE`。

- 禁止一口气输出几千字假装老师完成授课；每轮仅一个或少量教学目标，必要时让学生作答。
- 不只问「听懂了吗」；需用测验/练习客观检验掌握程度。
- 事实类讲解优先依赖已上传课程资料，并引用文件与页码；资料没有覆盖时标记通用知识/检索来源。
- 随学生答题记录：知识点、难度、作答、对错、时间、提示次数、错因、复习时间。
- 基于可解释学习记录更新 Learner Persona，允许用户编辑与删除记忆。

## 每阶段交付定义

P0：课程生成、文件解析与来源引用、教师对话、测验反馈、账号数据持久化。
P1：互动白板、Deep Learn、速查表、闪卡、知识图谱、学习计划、错因画像与主动学习动态。
P2：可渲染视频、深度研究、资料导出、教师风格、模型路由、费用与多租户管理。
P3：授权的 LMS 连接、课程广场、实时语音、班级与教师后台。
